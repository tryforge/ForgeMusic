# $findExtractor
Find an extractor by name.
## Usage
```
$findExtractor[name]
```
## Fields
| Name |            Description             |  Type  | Required | Rest |
|------|------------------------------------|--------|----------|------|
| Name | The name of the extractor to find. | String | Yes      | No   |
